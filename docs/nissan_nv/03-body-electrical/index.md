# Section 3: Body Electrical {#body-electrical}

This section covers the factory body electrical system and the aftermarket
Viper alarm and SmartStart remote start installed on it. Exterior lighting is
controlled over CAN: the BCM reads the switches and the IPDM E/R drives the
lights. The Viper taps into that system through T-harnesses behind the
driver-side dash.
