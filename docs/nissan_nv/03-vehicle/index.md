## Viper alarm & SmartStart {#viper}

| Item | Value |
| :--- | :---- |
| System | Viper alarm with SmartStart remote start |
| Install method | T-harnesses on the factory connectors - no factory wires cut |
| Brain location | Behind the driver-side dash |
| Brain / SmartStart module models | **TBD** |
| Bypass / data interface module | **TBD** |

!!! warning "Check the Viper wiring before a Nissan module"
    The Viper T-harnesses sit in line with factory body circuits and the CAN
    network behind the driver-side dash. A loose connection there has killed
    the headlights, high beams, and fogs while the van still started and
    drove normally. When factory functions fail in groups, check this bundle
    first.
