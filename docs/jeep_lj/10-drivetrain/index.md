## System Overview

- Transmission donor: 2015-2019 RAM 1500 EcoDiesel 4x4 (ZF 8HP70/845RE)
- Driveshafts: Custom (Tom Woods) - measure at final ride height
- Wheelbase: 110.5" (stretched ~7" from stock 103.4")
