# 10.8 - Brakes {#brakes}

/// html | div.product-info

**Type:** Four-wheel disc, electro-hydraulic boost

**Calipers and Rotors:** Factory Ford Super Duty, four corners

**Pads and Rotors:** PowerStop Z36 Truck & Tow, front and rear

**Booster:** Bosch Gen 2 iBooster (see [Brake Booster][brake-booster])

**Master Cylinder:** Wilwood Tandem Compact, 1-1/8" bore

**Park Brake:** Factory drum-in-hat, mechanical lever

///

Axle-side brake hardware and system sizing for the Super Duty axles. The
booster, master cylinder mounting, adapter, harness, firewall plate, and
plumbing are documented on the [Brake Booster][brake-booster] page.

## Calipers and Rotors

| Corner | Hardware |
| :----- | :------- |
| Front | Factory Super Duty caliper and rotor ([Front Axle][front-axle], Dana 60) |
| Rear | Factory Super Duty caliper and rotor with drum-in-hat park brake ([Rear Axle][rear-axle], Sterling 10.5) |
| Pads and Rotors | PowerStop Z36 Truck & Tow kit, front and rear, 2005-2007 F-250/F-350 SRW application[^owner-notes] |

!!! warning "Kit Year Range"
    The Z36 kit application is listed as 2005-2007. The donor axles can be
    2005-2010. Match the kit to the donor axle years before ordering.

## Booster and Master Cylinder

| Specification | Value |
| :------------ | :---- |
| Booster | Bosch Gen 2 iBooster, direct mechanical pushrod, M8x1.25[^owner-notes] |
| Pedal Ratio | Approximately 4:1; verification {{ tbd(301) }} |
| Master Cylinder | Wilwood Tandem Compact, 1-1/8" bore[^mc-bore] |
| MC Adapter | Back Bay Customs (see [Brake Booster][brake-booster]) |
| Harness | Tulay's Gen 2 (see [Brake Booster][brake-booster]) |
| Firewall Plate | 60x80mm pattern (see [Brake Booster][brake-booster]) |

!!! info "Master Cylinder Sizing"
    The 1-1/8" bore is sized for knockback margin with the Super Duty calipers,
    not steady-state caliper volume. It supersedes the 1.00" bore chosen for the
    TJ Rubicon calipers.[^mc-bore]

## Park Brake

Factory drum-in-hat in the rear rotors, mechanical lever. Cables built at full
droop.[^owner-notes]

## Lines and Proportioning

- Braided flex hoses at each axle, measured at full droop ({{ tbd(86) }}); plumbing on the [Brake Booster][brake-booster] page
- Adjustable proportioning valve on the rear circuit ({{ tbd(60) }})
- Front/rear bias starting point approximately 62/38[^owner-notes]
