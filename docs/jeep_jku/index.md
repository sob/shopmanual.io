# Jeep Wrangler JKU {#jeep-wrangler-jku}

## Project Overview

A 2012 Jeep Wrangler JK Unlimited with the 3.6L. Documentation starts with
the power system:

- A **Genesis Offroad dual battery system**, an older-generation kit with Genesis's own smart isolator, holding two Odyssey AGM Group 34 batteries. There is no DC-DC charger.
- A **SwitchPros SP-9100** 8-switch panel for the accessories, wired directly to the AUX battery.
