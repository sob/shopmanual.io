# Jeep Wrangler JKU {#jeep-wrangler-jku}

## Project Overview

A Jeep Wrangler JK Unlimited. Documentation starts with the power system:

- A **Genesis Offroad dual battery system**, charged by Genesis's own smart combiner. There is no DC-DC charger.
- A **SwitchPros SP-9100** 8-switch panel for the accessories.
