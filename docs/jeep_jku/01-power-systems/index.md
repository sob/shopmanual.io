# Section 1: Power Systems {#power-systems}

## System Overview

The JK is a 2012 JKU with the 3.6L and a **12 V** system. Two Odyssey AGM
Group 34 batteries sit in an older-generation **Genesis Offroad dual battery
kit**. The **Genesis smart isolator** connects the batteries so the
alternator charges both, and separates them when the cranking battery falls
to 12.7 V. There is no DC-DC charger. A **SwitchPros SP-9100**, planned as
the main accessory switch panel, will wire directly to the AUX battery.
