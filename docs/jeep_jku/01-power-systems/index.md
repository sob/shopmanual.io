# Section 1: Power Systems {#power-systems}

## System Overview

The JK is a **12 V** system. Two matching Group 34 batteries sit in a
**Genesis Offroad dual battery kit**. The **Genesis smart combiner** links
the batteries while charging and separates them when voltage falls. There is
no DC-DC charger. Accessories take power from the kit's power bus bar, which
is on the AUX side. A **SwitchPros SP-9100** is planned as the main accessory
switch panel.
